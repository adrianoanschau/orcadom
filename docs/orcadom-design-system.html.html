Orcadom Design System

Um canvas claro e calmo, com a linguagem de um caderno de contas — tipografia com personalidade em vez do dashboard fintech escuro que virou padrão do setor.

Paleta

Um único acento de marca (verde-petróleo) para ações e navegação. As cores semânticas de receita, despesa, transferência e pendência são fixas — nunca reaproveitadas para outro fim, para que o usuário aprenda a associá-las com confiança.

Tipografia

Fraunces para títulos e nomes de marca — traz o peso editorial de um livro-caixa. Manrope para toda a interface e para valores monetários, sempre com algarismos tabulares para que os números fiquem alinhados em listas e extratos.
